# Security policy

This repository contains documentation and AI instruction files only: no executable code, no dependencies, no services.

If you find something that should not be public (personal data, confidential information, a credential committed by mistake) or a way the Lean Advisor instructions could be abused, please **do not open a public issue**. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Reports are handled by the author on a best-effort basis.
